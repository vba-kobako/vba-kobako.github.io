月末に、売上の一覧から担当者ごとの行だけを取り出して、別のシートに貼る。そんな作業をしている方は多いと思います。1人ぶんならすぐ終わりますが、人数が増えると手間がふえ、コピーもれも心配になります。

マクロ（Excel に作業の順番を覚えさせるしくみ）を使わなくても、Excel の機能だけで少し楽にできます。ここでは流れだけを短く紹介します。

## 流れは「絞る、コピー、貼る」

1. 一覧の中のセルを1つクリックして、［データ］タブの［フィルター］を押します。オートフィルター（条件に合う行だけを表示し、ほかの行をいったん隠す機能）が使えるようになります。
2. 見出しに出た▼を押し、「担当者」の列で取り出したい人の名前だけにチェックを入れて［OK］を押します。データは消えず、隠れているだけです。
3. 絞りこんだ表を、見出しから最後の行まで選んでコピーします（Windows は Ctrl + C、Mac は Command + C）。
4. 貼りつけ先のシートのセルをクリックして貼ります（Windows は Ctrl + V、Mac は Command + V）。

![担当者の列で絞りこんだところ]({{ '/assets/img/filter-copy/1.png' | relative_url }})

絞りこんだあとにコピーすると、隠れている行は入らず、見えている行だけが貼られるのがふつうです。貼ったあとで、その人の行だけか確かめてください。

![見えている行だけが貼りつけられる]({{ '/assets/img/filter-copy/2.png' | relative_url }})

## 隠れた行までコピーされるとき

行番号を右クリックして手作業で隠した場合などは、隠れた行がいっしょに入ることがあります。そのときは「可視セル（画面に見えているセル）」だけを選んでからコピーする方法があります。Windows では、コピーする範囲を選んだあと、次のどちらかを試せます。

- Alt + ;（セミコロン）を押す
- ［ホーム］タブ→［検索と選択］→［条件を選択してジャンプ］→［可視セル］を選んで［OK］を押す

Mac の手順は、ここでは載せていません。

![見えているセルだけを選ぶ]({{ '/assets/img/filter-copy/3.png' | relative_url }})

## この方法のむずかしいところ

人数ぶんだけ「絞る、コピー、貼る」をくり返すので、担当者が多いと時間がかかります。絞りこみを戻し忘れて別の人の行が混ざることもあり、元の一覧が変わったときは最初からやり直しになります。担当者が数人なら足りることが多いと思いますが、人数が多いときや毎月くり返すときは、マクロにまかせる方法もあります。

## くわしい手順は note で

画面つきのくわしい手順は、note の「業務効率化Toolbox」にまとめています。マクロをはじめて使う方向けの基礎シリーズも、同じ場所にあります。
